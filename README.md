# 21 Savage w/ Authentication 

A hands-on full-stack application designed to practice implementing authentication and debugging an older codebase.

## How to Navigate
Sign Up / Login: Create an account or log in to access the application.
Message Board: Submit messages and watch them populate in the message list through backend functionality.
Like & Dislike: Interact with messages using the thumbs-up and thumbs-down buttons to increase or decrease their total like count.
Delete Messages: Remove messages from the board when needed.
Explore the application and get hands-on experience working with authentication, backend logic, and full-stack functionality!

## Features
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, express, MongoDB, passport

## Installation for your own project

1. Clone repo
2. run `npm install`

## Usage

1. run `node server.js`
2. Navigate to `localhost:8080`
