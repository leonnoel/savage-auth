## Project Overview

Savage Auth is a hosted messageboard that users can use to post, upvote and downvote, and delete messages.

- Post messages
- Delete Messages
- Up/Downvote messages

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/Savage-Auth.git
````

2. Navigate to the project directory:

```bash
cd savage-auth
```

3. Install Dependencies:
```bash
npm install
```
4. Start the server:
```bash
npm run dev
```
5. Open your browser and go to:
```bash
http://localhost:9080
```

## Usage

1. Login to account or sign up if you don't have one.
2. Create messages to post to messageboard.
3. View and up/downvote other messages.
4. Delete messages.
