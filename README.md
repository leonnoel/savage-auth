## Savage-auth
<img width="1920" alt="image" src="https://github.com/user-attachments/assets/7b86ed89-7167-4918-9637-182d6cae7eb3" />


This project provides the foundational server-side structure for a full-stack web application, utilizing Node.js with the Express.js framework to create a robust system with integrated user authentication. The application incorporates a suite of standard middleware—including Morgan for logging, Body-Parser for data handling, and Cookie-Parser/Express-Session for managing sessions—and uses Mongoose to establish a connection to a MongoDB database. Key to the architecture is the implementation of Passport.js with Connect-Flash, which handles secure user login, registration, and persistent login sessions. Once the database connection is successfully established, the application loads its defined routes, making all backend functionality available via the specified port.
